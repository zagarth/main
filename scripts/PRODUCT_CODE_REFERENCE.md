# Product Code Reference Guide

## Classic Bands Suffix Meanings

### Profile/Edge Type Suffixes

- **R** = Rectangular Cut (flat profile)
- **B** = Beaded Edge (decorative beaded edge detail)
- **T** = Tiffany Profile (rounded comfort fit, 1.5mm thick traditional design)

### Width Indicators

The number in the product code typically indicates the width in millimeters:
- **200** = 2.0mm
- **250** = 2.5mm
- **300** = 3.0mm
- **380** = 3.8mm
- **400** = 4.0mm
- **450** = 4.5mm
- **500** = 5.0mm
- **550** = 5.5mm
- **600** = 6.0mm
- **700** = 7.0mm
- **1000** = 10.0mm

### Thickness Indicators (Tiffany Profile)

When combined with T (Tiffany):
- **3T18** = 3mm width, Tiffany profile, 1.8mm thick
- **4T00** = 4mm width, Tiffany profile, standard thickness
- **5T00** = 5mm width, Tiffany profile, standard thickness

### Gender Suffixes

- **M** = Men's version
- **L** = Ladies' version

Note: M and L versions share the same base product ID and can use the same images.

### Metal Type Prefixes

- **S** = Sterling Silver (.950 Silver)
- (No prefix) = Gold (10K, 14K, or 18K available)

### Special Designations

- **P** = Polished (e.g., 5344PM = Polished center, Men's)
- **D** = Diamond set (e.g., 266DM = Diamond, Men's)

## Examples

- **300RL** = 3mm width, Rectangular cut, Ladies'
- **4T18M** = 4mm width, Tiffany profile, 1.8mm thick, Men's
- **400BL** = 4mm width, Beaded edge, Ladies'
- **S400RM** = Sterling Silver, 4mm width, Rectangular cut, Men's
- **5344PM** = 5.344mm width, Polished center, Men's

## Usage Notes

1. Base product IDs (without M/L suffix) can be used to group both genders
2. Images are shared between M and L versions
3. Only one image needed per base product (e.g., 300R covers both 300RM and 300RL)
4. Multiple profile types may exist for same width (e.g., 400, 400R, 400B, 400T all 4mm)
